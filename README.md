# Advanced Android Keyboard

An independent Android keyboard combining Google Gboard typing aesthetics with desktop-grade modifier controls, precision cursor navigation, and text selection/editing tools.

## Operating Modes
1. **Normal Mode**: Standard QWERTY, optional number row, suggestions, symbols, spacebar cursor trackpad.
2. **Advanced Mode**: Desktop modifier toolbar (Ctrl, Alt, Shift, Fn, Tab, Esc, Home, End, Del, Ins).
3. **Editing Mode**: 4-way precision D-pad, text selection toggle, word/line navigation, editing shortcuts.

## Build Instructions
Run `./gradlew assembleDebug` or use the included GitHub Actions workflow.
