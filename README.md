# Advanced Android Keyboard

An independent Android keyboard with desktop-grade modifier controls, precision cursor navigation, and text selection/editing tools.

## Operating Modes
1. **Advanced Mode (ADV)**: Full QWERTY with dedicated desktop modifier toolbar (Ctrl, Alt, Shift, Fn, Tab, Esc, Home, End, Del, Ins) and spacebar trackpad.
2. **Editing Mode (EDIT)**: 4-way precision D-pad, text selection toggle, word/line navigation, editing shortcuts.

## Build Instructions
Run `./gradlew assembleDebug` or use the included GitHub Actions workflow.
